# 健康管理Webアプリケーション（グループ開発）

▶️ [デモサイトはこちら]([https://todolistbyshk.netlify.app/](https://noona-diet-main.netlify.app/])

## プロジェクト概要

このプロジェクトは、食事と水分摂取の記録を通して、ユーザーが健康管理を行えるWebアプリケーションです。  
チームで役割を分担し、フロントエンドとAPI連携、可視化機能などを実装しました。

---

## 私の担当機能（branch/sh）

### 水分摂取トラッキング機能の実装
- `water_tracking.html`、`water_tracking_function.js`、`water_tracking_style.css`の作成を担当
- 主な機能:
  - ユーザーが水分摂取量（ml）を記録可能
  - 目標値（2000ml）に対する達成率を自動計算
  - 入力バリデーション、初期化ボタンの実装
